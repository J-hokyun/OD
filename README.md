# 진행기간
**2023.12~2024.01**
# 프로젝트 소개
- 사용자가 원하는 음성을 AI에 학습시켜 학습시킨 음성으로 오디오 북을 들을 수 있도록 하는 플랫폼입니다.
- 사전에 등록된 책을 들을 수 있으며 원하는 학습시킨 음성 뿐만 아니라 원하는 목소리로 오디오 청취가 가능합니다.
- 마이페이지를 통해 좋아요 목록, 등록 성우, 신규 도서 신청 기능등을 제공합니다
- 책 사업자는 자신이 등록한 책의 청취 수요를 확인할 수 있으며 북 썸네일을 변경할 수 있습니다.
